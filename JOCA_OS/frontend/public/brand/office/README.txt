GIFs for the "The Office" theme.

Drop files here with these names and they become the sidebar icons
(only with The Office theme active; reload the page after you add them):

  dashboard.gif    -> Dashboard
  tarefas.gif      -> Global Tasks
  automacoes.gif   -> Automations
  agentes.gif      -> Agents (navigation item)
  sessao.gif       -> Quick session and loose agents
  definicoes.gif   -> Settings
  projectos.gif    -> each project in the sidebar

Whatever is missing keeps the drawn icon. There is no need to edit code.

This folder is in .gitignore deliberately: the GIFs from the series are third-party work and
this repository is public. They stay on this machine, they do not travel in the push.
