# JOCA Memory Index

Catalog of the Brain's components. **Inventory verified on disk on 2026-08-20:**
**145 skills · 103 agents (67 generated + 36 curated) · 29 commands · 7 rules (+`README.md` = 8 files in `rules/`) · 1 workflow · 10 hooks · 21 scripts.**

> This file is maintained by hand and is easy to let rot. Whoever adds/renames/removes a
> component updates it **in the same session** — see `/save` STEP 6 and `/upgrade-joca` §5.6.
> Real counts at any moment:
> ```bash
> cd JOCA_Brain && for d in skills agents commands rules; do echo "$d: $(ls .claude/$d/*.md | wc -l)"; done
> ```

## Core
- [soul.md](soul.md) — personality engine: drives, decision filters, states, alignment with the user. Base of every session (`@import` from `CLAUDE.md`).
- [SKILL_INDEX.json](SKILL_INDEX.json) — **light** index of the skills (name/path/description/triggers). This is what relevance matching reads; the skills are never pre-loaded. Generated by `.claude/scripts/build-skill-index.py`.
- [tools/mcps.md](tools/mcps.md) — connected MCP servers + markitdown setup for `/know`.
- [tools/clis.md](tools/clis.md) — inventory of external CLIs (function + macOS/Windows installation + interactive auth).

## Agents (105 = 69 generated + 36 curated)

**67 generated execution agents** (`<skill>-agent`) — one for each direct-execution skill, created
by `node .claude/scripts/skill-agents.mjs` from the skills themselves. Each one reads its skill as
Step 0, so it has the same doctrine; the difference is **where it runs**. 1 part → read the skill inline;
≥2 independent parts → dispatch one agent per part, in the same turn.
**They are not edited by hand** — you edit the skill and regenerate it.

**36 curated agents:**

| Group | Agents |
|---|---|
| Review & tests | `tester-code` · `tester-ui-ux` · `tester-performance` · `tester-security` · `tester-api` · `tester-ratelimit` · `codex-review` · `prd-reviewer` |
| Orchestration | `master-orchestrator` (playbook adopted by the main loop, **not** a `subagent_type`) · `task-router` (classifies and stops) · `self-improver` · `gemini-auditor` |
| Research & analysis | `deep-research` · `seo-analyst` · `log-debugger` · `query-debugger` |
| Generation & media | `img-gen-google` · `img-gen-openai` · `gemini-brain` · `video-gen` · `watch` |
| Backend / Laravel | `laravel-refactor` · `filament-builder` · `security-review` · `tech-debt-auditor` · `pr-repair` · `deploy-executor` |
| Specialists | `payment-integration` · `dependency-auditor` · `design-system-audit` · `skill-evaluator` · `skill-improver` · `a11y-fixer` |
| Autonomy & personal | `knowledge-ingest` (`/know`) · `personal-comms` |
